## 🛠 About this repo

A single-page static site — everything lives in `index.html` (inline CSS and JS, no build step, no framework, no dependencies beyond the Satoshi webfont). It follows the OS light/dark setting, honors reduced-motion preferences, and stays readable with JavaScript disabled.

Published to GitHub Pages from `main`; `CNAME` pins the custom domain.

To preview locally:

```bash
python3 -m http.server 8000
```
